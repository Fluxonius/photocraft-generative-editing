# PhotoCraft Generative Editing

Переносимый Agent Skill для generative fill, добавления/замены объектов, детализации локальных вставок и generative expand через PhotoCraft + внешний генератор.

Skill объясняет агенту не только как получить картинку, но и как вставить её: сохранить масштаб оригинала, точно совместить фрагмент, выделить нужные части маской, согласовать цвет, освещение, резкость, зерно и ретушь, а затем проверить защищённые пиксели. При удалении маска охватывает весь восстановленный участок: сам объект, его тени, отражения и остаточные края, включая отдельные области вдали от силуэта. Чужие тени и отражения сохраняются. Нативный проект сохраняет слои и маски.

## Установка из GitHub

Репозиторий: https://github.com/Fluxonius/photocraft-generative-editing

Попросите агента: «Установи skill из https://github.com/Fluxonius/photocraft-generative-editing/tree/main/skills/photocraft-generative-editing».

## Ручная установка одного skill

Устанавливается папка `skills/photocraft-generative-editing`, а не весь проект. В Codex можно поместить её в `~/.agents/skills/` или настроенный каталог skills. Например, из корня проекта:

```sh
mkdir -p "$HOME/.agents/skills"
cp -R skills/photocraft-generative-editing "$HOME/.agents/skills/"
```

Если целевая папка уже существует, сначала сравните версии: пример не предназначен для бесконтрольного объединения старых файлов. Встроенный Skill Installer может установить папку skill непосредственно из GitHub. При установке из ZIP переносите только папку `photocraft-generative-editing` в каталог skills соответствующего агента. В другом агенте используйте его документированный каталог/механизм установки SKILL.md. Название MCP-сервера может отличаться.

После установки проверьте, что skill появился в списке вашего агента. Если список не обновился, начните новую сессию. Установка skill не настраивает PhotoCraft или MCP автоматически.

## Что нужно для работы

- PhotoCraft и действующее подключение MCP; для работы в окне — именно live bridge. **Все операции с PhotoCraft выполняются обязательно через MCP.** Если подключения нет, агент помогает его настроить перед редактированием. Прямой CLI, HTTP/RPC или управление кликами не используются как обходной путь. Внешняя генерация и локальная проверка пикселей могут выполняться отдельными инструментами.
- Генератор с редактированием по референсу: например, встроенный ChatGPT ImageGen, если он доступен в текущем агенте. Skill не предоставляет подписки, модели или API-ключи.
- Python 3.10+ и Pillow только для необязательного helper-инструмента. Установить в выделенное окружение можно через `python -m pip install -r requirements.txt`.

Тексты skill на английском для переносимости. Примеры запросов могут быть на русском:

- «Используй $photocraft-generative-editing: добавь очки девушке в открытом документе, сохрани лицо и волосы, оставь вставку отдельным слоем».
- «Удали этот предмет, сгенерировав только выделенный участок; проверь шов, свет и зерно».
- «Расширь холст слева и справа до широкого кадра, сохрани оригинал без изменения масштаба».
- «Перегенерируй только крупный фрагмент с объектом, чтобы не увеличивать маленькую генерацию всего кадра».

## Структура

- `skills/photocraft-generative-editing/SKILL.md` — устанавливаемая точка входа.
- `references/` внутри skill — fill, expand, качество вставки, генераторы, MCP, аудит и источники.
- `scripts/pixel_guard.py` внутри skill — геометрия, извлечение контекста и точная проверка защищённых пикселей.
- `tests/` — функциональные проверки helper-инструмента на синтетических изображениях.
- `docs/VALIDATION.md` — фактически выполненные проверки и ограничения.

Подробности протокола не копируются целиком: skill направляет к нужной справке и требует обнаруживать реальные команды установленной версии. Проект не зависит от личных файлов, этого чата, абсолютных путей или секретов.

## Проверка проекта

```sh
python3 -m unittest discover -s tests -v
python3 skills/photocraft-generative-editing/scripts/pixel_guard.py --help
# Необязательная проверка настоящего движка, только на временных синтетических файлах:
PHOTOCRAFT_CLI="/absolute/path/to/photocraft-cli" python3 -m unittest discover -s tests -v
```

`pixel_guard.py` проверяет поддерживаемые 8-битные lossless-экспорты. Для 16/32 бит и CMYK/Lab нужен отдельный проверенный путь сравнения без потери глубины; helper отказывается от неподдерживаемого входа. Визуальное совпадение цвета/ретуши не заменяется тестом пикселей. Искусственно восстановленные детали не являются реальными деталями исходной камеры.

Материалы написаны заново с атрибуцией открытых источников в `references/sources.md`. Проект независимый; это не официальный продукт OpenAI, Adobe или PhotoCraft. Проверенная область совместимости указана в отчёте; нельзя считать каждый генератор и каждую ОС автоматически протестированными.
